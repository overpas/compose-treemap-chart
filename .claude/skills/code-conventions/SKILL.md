# Code conventions

The rules any work on this project must abide by.

## General

- Keep changes minimal as long as it satisfies a goal.
- Write no comments in the code.

## What to read

| If you are about to                                                                                  | Read                           |
|------------------------------------------------------------------------------------------------------|--------------------------------|

| Change the public API, add a layout algorithm, change the sample or the benchmark, or add a module | `references/architecture.md`   |
