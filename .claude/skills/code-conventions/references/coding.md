# Coding

## General

- Don't edit the code that doesn't affect the task you are working on.
- Keep visibility of interfaces, classes, functions, properties minimal. In the published library
  modules, every public declaration is part of the API that the users depend on.

## Kotlin

When writing kotlin code use skills:

- /kotlin-control-flow
- /kotlin-api-design

When using kotlin concurrency features, coroutines, suspend functions, Flow, use
/kotlin-concurrency-and-flow skill.

## Compose

When writing compose code always use skills:

- /compose-component-design
- /compose-state-and-effects

When working on animations in compose use /compose-animations skill.

When working on compose UI performance, compiler stability reports or the stability configuration
files, use /compose-performance skill.

When writing or reviewing Jetpack Compose UI for TV, keyboard, desktop, accessibility focus, D-pad
navigation, FocusRequester, focusProperties, key events, or initial focus behavior, use
/compose-focus-navigation skill.
